# ⚡ Git Cheat Sheet

💡 A **complete Git command reference** for developers — from beginner to advanced.

---

## 🔥 CREATE COMMANDS

| Command | Effect |
|--------|--------|
| `git init` | Create a new local git repository |
| `git clone <url>` | Clone a remote repository locally |

---

## ⚡ LOCAL CHANGES

| Command | Effect |
|--------|--------|
| `git status` | Get update on locally changed files |
| `git diff` | Show difference between working directory and staging area |
| `git diff --staged` | Show difference between staging area and last commit |
| `git add <files>` | Add files to staging |
| `git add .` | Add all changes |
| `git add -p <file>` | Add selective changes |
| `git restore --staged <files>` | Unstage files |
| `git restore <files>` | Discard changes |

## 🌿 BRANCHES & TAGS

| Command | Effect |
|--------|--------|
| `git branch` | List branches |
| `git switch <branch>` | Switch branch |
| `git checkout <branch>` | Switch branch (older way) |
| `git branch <new>` | Create branch |
| `git branch -d <branch>` | Delete branch |

---

## 🌍 REMOTE OPERATIONS

| Command | Effect |
|--------|--------|
| `git remote -v` | Show remotes |
| `git fetch` | Download changes |
| `git pull` | Fetch + merge |
| `git push` | Upload changes |

## 🔥 UNDO COMMANDS

| Command | Effect |
|--------|--------|
| `git reset --hard` | Remove all changes |
| `git checkout HEAD <file>` | Restore file |
| `git revert <commit>` | Undo commit safely |
